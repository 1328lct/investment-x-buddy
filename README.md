# 投资 X Buddy

题目13「投资 X Buddy」的独立中文 Web 应用。面向需要保留过程、核验证据、随时中断与恢复的投资研究者。与 AlphaRadar、MarketScope 使用独立目录和应用状态。

> **当前是可运行的 Agent Harness DEMO**，不是已接入真实模型或实时行情的研究服务。所有数值为合成数据；规划与报告使用透明规则。没有真实金融 API、LLM、交易、外发或费用发生。请勿把合成样本结论用于真实投资。

## 本地启动

需要 Python 3；测试需要 Node.js 20+。无需安装依赖、构建或环境变量。

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
# 打开 http://127.0.0.1:4173
node --test tests/*.test.mjs
```

不能直接以 file:// 打开，因为使用 ES Modules。也可用任意静态网站服务器托管 dist/。应用除可选 Google Fonts 字体外无网络依赖；字体失败自动使用系统字体。

## 评委核心任务（约 90 秒）

1. 输入「比较沪深300与中证1000的估值和市场宽度」，点击开始研究，再执行计划。
2. 观察五项任务、调用次数、本地耗时、模拟成本与压缩事件。
3. 打开证据库，点击 E-1，核对原始 close、时点、单位、seed、生成公式和 CALL-1。
4. 查看研究产物中的合成样本事实、归纳、不确定判断与重评条件。
5. 申请导出，先拒绝，确认未产生文件；再次申请并批准，获得 Markdown 报告。
6. 选择中间检查点恢复，继续完成；已完成取数不会重复。
7. 在实验室切换「工具持续失败」并新建研究，观察最多3次尝试后缺失降级；缺失数据不产生正常结论。

## 产品选择

三栏研究桌面：左侧线程与记忆，中央计划、证据、产物与追踪，右侧 Harness 观察器。先给计划再执行，允许使用者在运行前检查范围。强调证据质量与过程控制，不以预测涨跌为结果。

## 架构

- `dist/engine.js`：无 UI 依赖的状态机、能力注册表、预算、故障、取数、压缩、检查点、审批与报告。
- `dist/app.js`：中文界面、线程管理、浏览器持久化、任务调度、溯源与文件下载。
- `dist/style.css`：桌面三栏 / 平板双栏 / 移动纵向布局、焦点状态。
- `tests/engine.test.mjs`：Node 内置测试，无第三方依赖。

研究对象包含 goal、symbols、tasks、evidence、traces、events、context、summary、memories、checkpoints、limits、approval 和 report。工具和证据数据均按值复制进入检查点；检查点不递归包含检查点列表。最多保留20个。

## AI 的角色

开发阶段由 Codex 参与需求拆解、UI、代码、测试与文档。运行时没有 LLM：`newThread()` 根据目标提取支持的标的，注册五项研究能力；`compile()` 基于有质量标签的证据形成可审计模板。未知标的明确默认沪深300/中证1000。规划器故障场景是本地故障注入，降级为规则规划器；不是实际模型服务故障。

长期记忆是用户研究偏好文本，新线程读取独立快照，压缩摘要及报告保留它们；本版本不会把任意自然语言偏好解释成新的可执行代码。继续研究会创建带 parentId 的关联线程。

## Harness 机制

| 机制 | 实际行为 |
| --- | --- |
| 线程、任务 | 创建、切换、删除；五项任务按状态执行 |
| 上下文 | 超过500字符时生成结构摘要，保留证据ID；原始证据不删 |
| 记忆 | 增删改与 localStorage 持久化；新线程读取快照 |
| 检查点 | 执行前及任务完成后保存；恢复到 paused，继续剩余任务 |
| 刷新恢复 | 运行中的线程安全转为暂停，不自动继续；审批失效 |
| 暂停/取消 | 不再调度后续调用；在途 DEMO 结果丢弃 |
| 审批 | 本地 Markdown 导出使用一次、线程绑定授权；拒绝不下载 |
| 停止规则 | 调用次数、模拟预算、累计执行耗时任一触顶即暂停 |
| 异常 | 首次失败重试；持续失败最多3次后降级；缺失/过期显式阻断正常归纳 |
| 可观测 | 入参、输出、错误、attempt、时间、duration、成本估算和事件 |

审批演示只执行本地下载，没有真实外发、高风险服务或交易。浏览器侧授权不是服务器安全边界；未来真实高风险工具必须增加服务器校验和身份鉴别。预算只能新建研究时设置，已触顶的研究可检查，但须新建并调整预算才能继续。

## 数据与溯源

未获得扶摇/iFinD授权，且本环境无可调用金融工具。没有使用受限数据或 API Key。扶摇和iFinD显示“未连接”，不是运行中的适配器。

每个合成证据包含：来源、field/value/unit、sampleTime、timezone、scope、seed、formula、callId、quality。seed 是标的和工具名的32位确定性散列；生成公式在证据抽屉逐条展示。样本固定为 `2026-10-20T15:00:00+08:00`。实验室的过期行情为2024年样本，缺失值保持 null，绝不补0。有效表示“合成样本可用于演示”，不表示真实、当前或可交易。

规则置信分72/100表示合成证据齐备，35表示存在缺失或过期；不是概率，也不是投资信心。归纳引用报告完整证据列表，不构成真实市场判断。

## 合规与安全

- 输出结构分为合成样本事实、归纳、不确定判断，明确研究与样本时点。
- 输入层拦截常见买卖、仓位、收益保证、确定性涨跌关键词；静态报告模板不生成交易建议。关键词规则并非生产级合规模型。
- 不存在交易、订单、账户写入、真实消息发送工具。
- 用户文本经过 HTML 转义。工具输出仅作为数据，不被执行为代码或指令。
- 成本、token为模拟估算；duration 为本地测量，非网络接口延迟。
- 没有密钥、用户隐私或持仓样本。不要将私密信息输入目标或记忆。

## 存储、权限与环境变量

仅在当前浏览器 `localStorage['xbuddy-v1']` 存储，无登录、云同步和服务器。不同站点来源的浏览器存储彼此隔离，清除浏览器数据会丢失研究。输入、记忆、检查点均在本地。存储不足时显式提示。暂不支持 JSON 导入和跨设备恢复。

环境变量：无。`.env.example` 说明了未来真实服务接入的位置，不能将真实 Key 放进静态前端。真实集成应通过具备身份、审批、限流、超时和字段校验的服务端代理。

## 部署

静态托管根目录指向 `dist/`；相对资源路径支持 GitHub Pages 项目子目录。仓库已提供根目录 index.html 跳转到 dist/，并包含 .nojekyll；GitHub Pages 可直接选择 main 分支和 /(root)。测试命令见上文；无需 build。公开 URL 和仓库状态以 `DELIVERY_STATUS.md` 的实际记录为准，未验证地址不得视为交付。

## 已知边界与未做事项

真实 LLM 与金融 API 适配器、多用户鉴权、服务端长期运行、真实外发审批、语义级自然语言规划、自动政策/新闻获取、生产级合规、向量记忆、流式模型输出、云持久化、交易能力均未实现。只支持列出的标的关键词；任意股票代码不会自动识别。报告是规则模板，不是开放式深度研究。移动端使用纵向观察器，未实现拖拽桌面布局。演示视频未制作，优先必交源码、文档和验证。

验证记录：`AI_USAGE_AND_VALIDATION.md`、`TEST_PLAN.md`、`TEST_RESULTS.md`。
